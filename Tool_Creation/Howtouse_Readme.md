# Housekeeper

A web tool that helps you create professional evidence briefs for Ontario Landlord and Tenant Board (LTB) hearings.

Upload your evidence files — photos, PDFs, Word documents, spreadsheets, even iPhone HEIC images — organize them into numbered tabs, and generate a court-ready PDF with a title page, table of contents, tab dividers, and properly numbered pages.

## Use It Now

1. Visit Directly through the link:
**https://housekeeper-2kp7.onrender.com/**

2. Or open the Colab_Jupyter Notebook and run the code in the folder:
**Colab_Jupyter Notebook**

## How to Use

1. **Step 1** — Enter your case info: file number, hearing date, party names, case type.
2. **Step 2** — Upload your evidence files (photos, PDFs, Word docs, etc.).
3. **Step 3** — Drag files into numbered tabs to organize your evidence.
4. **Step 4** — Hit Generate and download your evidence brief as a PDF.
